# Micro OS — the names an image of the release promises
#
# One line: a name and where it comes from. `make x86-smoke` boots the image of
# the release and asks the machine for every line of this file: a file of /bin
# or of /bin/ports is in the listing of that directory and `help NAME` finds it
# through PATH, and a command of the shell answers `help NAME` at all.
#
# The file is the one place of the list. A release note or a page of the docs
# that promises a name adds it here in the same change, and a name here that
# the image does not carry is the failure of that promise: 1.9 promised `kilo`
# in its notes and `date` was a command of the board only, so the owner's
# laptop answered `command not found` for a name the release had promised.
#
# The first column is the name, the second where it lives: `/bin`, `/bin/ports`
# (the programs of the SDK, `make ports-build`) or `shell` (a command of the
# kernel's own shell).
