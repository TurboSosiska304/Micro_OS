# Micro OS — the contract of the platform port, 1.13, as it was recorded.
#
# This file is the golden record of kernel/port/*.h: the functions a machine
# has to implement to be a port of this kernel. `make integrity` compares it
# with the headers and with the sources of every port, and the release gate
# asks for two independent ports that implement the whole list (the ESP32 and
# x86-64), with the host and the null port as the cheapest checks of the
# contract (docs/releases/1.0.md, section 1).
#
# The rules of the file:
#
#   * `api MAJOR MINOR` is the version of the contract, compared with
#     KERNEL_PORT_API_VERSION_* of kernel/port/info.h. The minor moves when a
#     function is added, the major when the meaning of one changes;
#   * every other line is `k_port_name header`, where the header is the one
#     that declares the function, from the directory of the headers. A name
#     that is declared and not recorded (or the other way round) is a failed
#     check, so a call that is added to the contract is added here too;
#   * the execution substrate (kernel/port_task.h, the k_port_task_* calls) is
#     not in this list: it is the part of a port that has no machine behind it
#     to be checked against, and the tests of the scheduler cover it. The
#     version of the contract is the version of the ten headers below.
#
# Eleven headers, 59 functions: console 5, cpu 2, exec 8, info 4, kv 5, lock 6,
# mem 6, mm 11, net 8, power 3, time 2.
#
# The two calls of kernel/port/cpu.h carry a weak default in the portable
# kernel (components/kernel/src/cpu_default.c): a port that predates them is
# one core, which is what the board is until its own work (ADR 0012). They are
# recorded with the word `weak` so that `make integrity` asks the ports that
# override the default for them and does not fail a port that does not. The
# wake of a core (ADR 0034) is the third of them: a port without a wake-up
# interrupt of its own leaves the task to the next tick of the core.
api 1 13
