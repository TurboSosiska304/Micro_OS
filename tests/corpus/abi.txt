# Micro OS — the ABI of the system, recorded for 1.0.
#
# This file is the golden record of the contract between the kernel and the
# programs: the table of the system calls, the numbers of the errors and of
# the flags, the layout of the structures that cross the door, and the header
# of a program image. The test `ksys: the ABI is the recorded one`
# (tests/cases/test_ksys.c) reads this file and compares it with the running
# kernel; the test of the format (`tests/cases/test_exec.c`) does the same for
# the frozen MOX1 image. A number, a name, a flag or a field that changes
# without a line here is a failed test, which is what "frozen" means.
#
# The rules of the file:
#
#   * one record per line, the fields separated by spaces, `#` starts a
#     comment that runs to the end of the line, an empty line is not a line;
#   * every name is checked against a table in the test, so a name the test
#     does not know is a failure and a name the file forgot is one too. The
#     test is the reader: a constant that is added to the kernel is added to
#     both sides in the same change;
#   * the number and the name of a call are compared with the live table of
#     ksys.c (ksys_name() and ksys_count()); the arity and the result are
#     documentation of the signature that the compiler checks through the
#     prototypes of kernel/ksys.h;
#   * a record of the layout names the width of a pointer: 8 is the host and
#     the x86-64 port, 4 is the board (Xtensa). The test reads the records of
#     the machine it runs on and requires the others to be there as well, so
#     the file is the record of both machines and not of one of them.
#
# The record is of 1.0 and every 1.x keeps it: a number is never reused, an
# old call keeps its number and its meaning, and a structure that crosses the
# door grows a new field only at its end or by a call of its own (statx is the
# second door of stat, ADR 0013).

# The number of the calls, compared with ksys_count().

# The table: number name arity result.

#

#   ssize   a count of the bytes, negative when it is an error
#   u32     an unsigned 32-bit number
