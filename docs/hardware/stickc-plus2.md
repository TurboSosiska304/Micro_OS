# M5Stack StickC Plus2 — железо

Источник: официальная документация M5Stack (SKU **K016-P2**).
Всё, что ниже, нужно сверять перед написанием драйверов: плата без PMIC, с
нестандартной логикой питания и общим пином IR/LED.

## Основное

| Параметр | Значение |
|---|---|
| SoC | ESP32-PICO-V3-02 (Xtensa LX6, 240 МГц, 2 ядра) |
| Flash | 8 МБ SPI |
| PSRAM | 2 МБ Quad |
| Экран | 1.14" TFT, 135×240, ST7789v2 |
| IMU | MPU6886 (акселерометр + гироскоп) |
| RTC | BM8563 |
| Микрофон | SPM1423 (I2S) |
| Батарея | 200 мА·ч, 3.7 В |
| USB | Type-C, USB-UART чип CH9102 |
| Размер | 48 × 24 × 13.5 мм, ~17 г |
| Питание | 5 В / 500 мА через USB |

| Сигнал | GPIO | Примечание |
|---|---|---|
| BUTTON A | G37 | |

## Питание и сон (важно!)

* PMIC **AXP192 отсутствует** — зарядка и питание ведёт сам ESP32.
* Включение: удерживать **BUTTON C** дольше 2 секунд.
* После пробуждения по RTC или кнопке программа обязана выставить **HOLD (G4) = 1**,
  иначе плата снова уйдёт в выключенное состояние.
* Выключение: удерживать BUTTON C (или вызов `esp_restart()` / `esp_deep_sleep`).
* Заряд батареи: при питании от USB батарея заряжается; ток зарядки и состояние
  читаются через ADC-делитель на G38.

## Проблемы, на которые натыкаются

* **Кабель C-to-C**: порт может не определиться. Лечится: выключить плату
  (долгое нажатие до загорания зелёного LED), затем подключить кабель заново.
* **PSRAM обязателен** в `sdkconfig`: без `CONFIG_SPIRAM=y` не будет 2 МБ RAM
  и не заработают `esp_psram`-буферы кадров.
* **G25 и G36**: если используете один как ADC-вход, второй надо перевести в
  режим float (`gpio_pulldown_dis(GPIO_NUM_25)` / `gpio_pullup_dis`).
* **G19**: включение ИК-диода гасит красный LED и наоборот.
* **Экран**: у Plus2 другой DC/RST (G14/G12), чем у StickC и StickC Plus
  (G23/G18). Код для StickC Plus на Plus2 не заработает.
* **Драйвер USB-UART**: на Plus2 это CH9102 (нужен отдельный VCP-драйвер),
  а не CH552/FTDI, как на StickC/Plus.

## Частоты и таймеры

* Основной тактовый сигнал: 240 МГц.
* Точный RTC-генератор 32.768 кГц — он же будильник deep-sleep.
* Таймеры ESP32: два блока по 4 таймера, 64-битный — под системный тик.
