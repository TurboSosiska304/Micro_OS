# Фаза 2 — файловая система, VFS и шелл

Программы платы получают дерево каталогов, файловую систему и шелл, который
умеет работать с файлами.

## Что появилось

* **MicroFS** — файловая система платы, как она описана в
  [docs/memory.md](../memory.md): секции DATA, META и INFO, адреса считаются
  от размера тома, META хранит карту свободных блоков и таблицу inode по
  16 байт, файлы растут цепочками блоков.
* **VFS** — файловые системы монтируются в точку дерева, пути разрешаются по
  самому длинному совпадающему префиксу.
* **procfs** — `/proc` с `version`, `uptime`, `meminfo`, `tasks`, `modules`,
  `/proc/self` и каталогом на каждую задачу с файлом `status`.
* **devfs** — `/dev` с `tty0` (консоль) и `null`.
* **Шелл** — `help`, `uname`, `uptime`, `ps`, `echo`, `sleep`, `dmesg`,
  `free`, `clear`, `modules`, `memtest`, `i2c`, `abi`, `display`, `pwd`,
  `cd`, `ls`, `cat`, `write`, `mkdir`, `rm`, `df`, `mount`, `reboot`.
* **Консоль на дисплее** — вывод шелла дублируется на экран платы, шрифт
  5×7.
* **Лог загрузки** уходит в `/log/start.log`, консоль остаётся читаемой.

## Ошибки, которые стоили времени

* **Путь корневого монтирования отвергался.** Проверка «точка монтирования
  должна быть целым каталогом пути» отклоняла любой путь ниже `/`. Корень —
  префикс любого пути.
* **Список каталога считал записи прошлого вызова.** Буфер записей
  статический и не очищался.
* **Виртуальный файл не заканчивался.** `/proc/uptime` генерировался снова
  и снова, и `cat` крутился вечно. Смещение дескриптора говорит, сколько
  текста уже прочитано.
* **Картинка на дисплее была сдвинута.** Память ST7789V2 — 240×320, а
  стекло панели 1,14" показывает только часть. Смещение стало переменной и
  меняется на ходу: `display <x> <y>`.
* **Шелл не повторял ввод.** Набранная строка появлялась только после
  Enter, теперь каждый символ повторяется сразу, а Backspace стирает его.
* **Флеш платы полон.** Для аварийного дампа места больше нет, он
  отключён.

## Что стоит запомнить

* Файловая система говорит с **блочным устройством**, а не с флешем.
  Тесты используют том в памяти, плата — раздел флеша.
* Каталог — тоже цепочка блоков, то есть каталог не ограничен одним
  блоком.
* Путь задачи и путь VFS — разные вещи: у задачи есть свой рабочий
  каталог, и VFS разрешает относительные пути относительно него.
* Буферы больше 4 КБ не кладутся на стек задачи: стек 8 КБ, и его съедает
  один буфер каталога.
