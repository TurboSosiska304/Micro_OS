# Micro OS 1.1.2

`1.1.2` is a patch of [`1.1.1`](1.1.1.md) for the shell. The cleanroom of
1.1.1 worked on the machine as a person and found that `ls` silently stopped
at sixty-four names, `tree` at sixteen, and that `cd ..` was not a path. The
volume, the syscall ABI and `MOX1` do not change; a machine of 1.1.1 takes the
image as it is, and the NVS and MicroFS survive.

## The directory is read as it is printed

`ls` kept a table of sixty-four entries and `tree` a table of sixteen; the
rest of a directory was not an error, it was simply absent. Both read the
directory through `readdir` in pieces now and print as they go. `tree -d`
counts the files it does not draw, and a tree deeper than six levels counts
the rest as `(deeper)`.

The price is the order: a sorted listing needs the whole directory in memory,
which is what the tables were for. `ls` prints in the order of the
filesystem; `/bin/ls`, the program of the image, still sorts. The trade is in
`docs/debts.md`, and the note in the release says so.

## A path is a path

`shell_resolve` builds the absolute path component by component: `.` and `..`
are resolved, `//` is one slash and a trailing `/` is none. `cd ..`,
`cd .`, `ls ..`, `cd /proc/..` and `cd /..` work now; before, any of them was
`no such file or directory` and the only way up was the full path.

## The small things of the console

* `help <command>` writes a long detail without the 192-byte line buffer and
  no longer cuts the sentence;
* `path ""` is refused - a reset is `path /bin:/usr/bin`;
* `umount /proc` and `/dev` are refused while they are mounted, and `umount /`
  says that the root stays and names `mkfs -y` where the machine has it;
* `df` of a path that is not there is `no such file or directory`;
* `config` on a machine without a store says so, and `config sync` fails
  instead of a false `0 saved`;
* `memtest` repeats an operation until the timer can see it; a block too fast
  is `too fast to measure`, not a speed a hundred times the memory;
* `write` says `1 byte` or `2 bytes`; `mkdir` over a directory says `is a
  directory`; the clock says `up N s, N ticks` in one shape.

## The checks

```bash
make test test-asan test-tsan  # the host
make test-smp
make x86-smoke                 # 185 checks
make x86-disk-smoke            # 25
make smoke                     # 69
make integrity
make idf-build
tools/device-test.sh /dev/ttyACM0
```

The 1.1.1 gates remain the evidence of the line: 600 seconds on x86-64 and
the board, and the host under TSan. The patch changes the shell, not the
filesystem, the scheduler, the ABI or the port.
