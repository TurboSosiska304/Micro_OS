# Micro OS 1.3.1

`1.3.1` is a patch of [`1.3.0`](1.3.md) for four defects that the first
copyleft packages and the 600-second session of the tag found. The volume, the
syscall ABI and `MOX1` do not change; a machine of 1.3.0 takes the image.

## The session of the tag

`make soak-smp` of `v1.3.0` ran out of its budget of ten seconds for a program
under load, and `execve` **returned** while the program was still running:

```text
tasks 2 -> 4
['init', 'shell'] -> ['init', 'shell', here, here]
```

The caller had stopped waiting; the task stayed in the table for ever, with the
console of the shell and a slot nobody reaps. The budget is a minute now, and a
program that outlives it is stopped with `SIGTERM` and reaped - a call that
returned cannot leave a task behind.

## The installer

A field the parser does not know is skipped, as `docs/wiki/pkg.md` promises; a
string value was not:

```c
if (*c->p == '"') {
    for (;;) { char ch = *c->p; if (ch == '"') { c->p++; return PKG_OK; } ...
```

The first character the walk looked at was the quote that opened the string, so
every value was skipped as empty and one `homepage` of an index made the whole
document unreadable. Found by the port of `patch`, which names its source in
the index.

## Two names

`rename` handed its pair of names to the kernel untouched, while `open`, `stat`
and `unlink` resolve them in the library: a relative name answered `EINVAL` for
`rename` alone, and a program that saves through a temporary name lost the
file. Found by the same package.

The shell printed `the program has finished` into the stream of the program, so
with a redirection the sentence landed in the file: the port of `gzip` caught it
as trailing garbage in a `.gz` that `gzip` then refused to read. The line is a
diagnostic of the shell and goes to the error stream.

## The checks

```bash
make test test-asan test-smp        # the host
make x86-smoke                      # the machine: 310
make x86-disk-smoke x86-net-smoke x86-vga-smoke x86-iso-smoke
make smoke                          # the simulator: 69
make test-minimal                   # the second host configuration
make soak                           # 600 seconds
make x86-user                       # the tar, without ESP-IDF
make integrity
make idf-build
tools/device-test.sh /dev/ttyACM0
```

The filesystem, the scheduler, the ABI and the port are the ones of `1.3.0`,
whose sessions remain the evidence of the line; this patch changes the library
of a program, the installer, the shell and the wait of a program.
