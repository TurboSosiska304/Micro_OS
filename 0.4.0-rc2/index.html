This version shipped without a wiki¶

Micro OS 0.4.0-rc2 was released before the wiki existed. The pages appeared with 0.5.0-rc2; there is no versioned copy of them to show for this tag, and inventing one would describe a tree nobody ran.

The stable address of the wiki points at the newest stable tag, 2.0.0; until a stable release carries a wiki, this note is what it leads to.

The release itself is still on GitHub: the tree of 0.4.0-rc2 and the source of the tag.
